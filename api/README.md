# Hello World

## Before you start

Please make sure to follow these steps

* Read Astroid's Terms: [https://astroid.cc/terms](https://astroid.cc/terms)
* Read Astroid's Privacy: [https://astroid.cc/privacy](https://astroid.cc/privacy)
* Have either a endpoint token (you got this in the registering progress. _Alternatively you can run the_ <mark style="color:purple;">`/generate-token`</mark> _command on discord to get a new one_) or master token (only available when you're selhosting Astroid's API and Database)
* Be aware that API requests are not undoable. Once done, it's done.
